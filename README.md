# 书签权重智能管理器 (Bookmark Weight Manager)

一个专为 Chrome 浏览器设计的轻量级、智能化书签管理扩展程序。它能够自动读取你的所有书签，并根据你在浏览器中的**常驻时间**与**重复打开频次**计算网页权重，按权重降序排列，助你高效管理和检索最常使用的核心网址。

---

## ✨ 核心功能特性

1. **全盘书签读取与精准匹配**：
* 自动安全读取浏览器的全部书签。
* 智能匹配：**仅对属于书签的网址进行权重追踪和累加**，非书签网址自动忽略，保持数据纯净。


2. **多维度智能权重计数规则**：
* **重复打开加分**：每次完整加载并打开一个书签网址，自动增加权重（默认 `+1`）。
* **常驻浏览器加分**：当网址在标签页中持续常驻达到指定时长（默认 `1 小时`），自动触发常驻加分（默认 `+5`），并通过后台 `chrome.alarms` 定时精确计算。


3. **降序清单与实时搜索**：
* 点击扩展图标即可弹出管理面板，所有有权重的网址将**严格按权重降序排列**。
* 内置实时搜索框，支持通过标题或网址关键字快速过滤查找。


4. **灵活的权重管理与重写**：
* **无权重过滤**：权重为 0 或无权重的网址默认不显示在清单中，保持界面清爽。
* **手动重写权重**：可随时点击“重写权重”按钮对任意网址指定新的分值。
* **删除权重**：支持一键清空或删除指定网址的权重记录。


5. **自定义规则设置页**：
* 提供独立的 `options.html` 设置页面，支持自由调整“常驻时间阈值（分钟）”、“常驻加分数值”以及“重复打开加分数值”，保存后**实时生效**。



---

## 🛠️ 技术栈与规范

* **规范标准**：完全遵循最新的 **Chrome Manifest V3** 开发标准。
* **核心 API**：
* `chrome.bookmarks`（书签读取）
* `chrome.tabs` / `chrome.alarms`（标签页监听与后台常驻计时）
* `chrome.storage.local`（本地高效持久化存储）

## 📦 安装与使用指南

如果你获取的是打包好的源码（如 `bookmark_weight_extension.zip`），请按照以下步骤在 Chrome 浏览器中加载安装：

1. **解压文件**：将下载的压缩包解压到本地某个文件夹中（例如命名为 `bookmark_weight_extension`）。
2. **打开扩展程序页**：启动 Chrome 浏览器，在地址栏输入并回车：
```text
chrome://extensions/

```


3. **开启开发者模式**：点击页面**右上角**的开关，启用 **“开发者模式” (Developer mode)**。
4. **加载扩展**：点击左上角的 **“加载已解压的扩展程序” (Load unpacked)** 按钮。
5. **选择文件夹**：在弹出的文件选择框中，选中刚才解压出来的 `bookmark_weight_extension` 文件夹。
6. **完成安装**：浏览器右上角将出现扩展图标，点击即可开始使用！

## ⚙️ 默认规则配置说明

你可以在弹窗右上角点击 **“规则设置”** 进入配置页，默认规则如下：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| **常驻浏览器时间阈值** | `60 分钟` | 网址在浏览器后台或前台持续打开达到该时间时触发。 |
| **常驻加分数值** | `+5` | 满足常驻时间后增加的权重积分。 |
| **重复打开每次加分** | `+1` | 每次完整打开/刷新加载书签网页时增加的权重积分。 |

## 💡 常见问题 (FAQ)

* **Q: 为什么有些网址没有出现在扩展的列表中？**
* A: 本扩展的清单**仅展示有权重（权重 > 0）的书签网址**。如果某个书签你从未通过它打开、或者常驻时间未达到标准，它将暂不显示。此外，**该网址必须已经存在于你的 Chrome 书签栏中**。


* **Q: 权重数据会丢失吗？**
* A: 所有权重数据均通过 `chrome.storage.local` 安全保存在你的本地浏览器中，卸载扩展或清除浏览器本地数据可能会被重置。
