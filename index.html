🔖 书签权重智能管理器

自动化管理 Chrome 书签，让最常用的网站永远排在最前列

🚀 立即获取扩展源码

完全遵循 Chrome Manifest V3 标准，轻量安全，本地存储保护您的隐私。

下载源码 ZIP 访问 GitHub 仓库

✨ 核心特性

🎯 智能权重追踪

自动记录书签网址的重复打开频次及常驻浏览时长，科学计算热度权重。

📊 降序清单展示

点击扩展图标，所有有权重的书签自动按热度降序排列，检索快人一步。

⚙️ 灵活自定义规则

支持自由调节常驻时间阈值、加分数值，并支持手动重写或清空指定网址权重。

📦 5分钟快速安装指南

  1. 点击上方按钮下载源码压缩包并解压到本地。
  2. 打开 Chrome 浏览器，地址栏输入并进入：chrome://extensions/
  3. 开启右上角的 开发者模式 (Developer mode)。
  4. 点击左上角的 加载已解压的扩展程序 (Load unpacked)。
  5. 选择解压出来的文件夹，安装即刻完成！
